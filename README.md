# Adventureworks-sales-dashboard
AdventureWorks Sales Performance Dashboard analyzing sales trends, profit, orders, and customer insights using Excel, MySQL, Power BI, and Tableau.

## Tools Used
- Microsoft Excel
- Power BI
- Tableau
- MySQL

## Dashboard Highlights
- Total Sales Analysis
- Profit and Profit Margin
- Year-wise Sales Trends
- Quarter-wise Sales Distribution
- Month-wise Sales Performance
- Top 5 Customers by Sales

## Dashboards Included
- Excel Dashboard
- Power BI Dashboard
- Tableau Dashboard
